## 💡 Cómo sacarles provecho (lo importante)
1. **No memorices nombres.** Pide la tarea normal: "edita este video", "audita la seguridad de cyberaudit", "haz el pitch deck de CodeCela" — la skill correcta se activa sola.
2. **Las combinaciones son donde está el poder**, ej:
   - Landing para cliente → `design-taste-frontend` + `seo` + `production-audit`
   - Video para tu canal → `video-use` + `taste` + `fal-ai-media`
   - CyberAudit SaaS → `cyber-neo` + `mantis` + `skill-creator` (para hacer tus propias skills de auditoría)
   - Cliente nuevo con su negocio → `ops-onboarding-cliente` → `ops-cotizacion-sitio` → `marketing-copy-pagina` → `dev-release-sitio`
3. Si quieres que una skill se vuelva hábito, pídela explícita: *"usa video-use para..."*.
